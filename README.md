# Emberwild — a KithCore example world

Emberwild is an independently distributed larger example game for **[KithCore](https://github.com/jspjut/kithcore) runtime API 1**, with a mostly complete starting zone and additional city/region content. It is a development starting point, not a finished MMO. Install this directory at `worlds/emberwild/` in a compatible engine checkout, or download the combined Emberwild starter. From the engine root, run `./start.sh --world emberwild`; the starter selects this world by default with `./start.sh`. Docker users run `docker compose -f compose.yaml -f worlds/emberwild/compose.override.yaml up --build`.

All commands below run from the **engine root**. Generated GLBs, preview PNGs and the exported-art ZIP are excluded from Git; gameplay builds its visuals from source factories and needs no asset download. Run `npm run build:world-assets` to regenerate and verify the complete library before the full regression suite after a fresh source checkout. Curated workshop downloads/previews require the separate build/preview steps below. Use `npm run test:emberwild` for the complete world regression suite and `npm run test:emberwild:browser` for the broad browser workflow. Existing named browser/asset scripts are routed through a disposable assembled development runtime; fixture paths must be absolute. See the engine deployment guide for adopting old `data/characters.json` files: the new default save path is `data/emberwild/`, and original saves are left untouched.

This repository contains world content, its presentation, art recipes/assets, story authoring material and regression tests. Core simulation and shared rules are supplied by the engine and are not vendored here. Content still uses trusted JavaScript for specialized rules/geography; this first extraction does not claim a fully JSON-based world.

For world exploration, see [the five-region atlas](docs/WORLD_ATLAS.md). An opt-in local `/developer` entry creates GM explorers with all travel unlocked; setup is documented in the engine’s `docs/DEVELOPER.md`.

The static continent now includes 6–10 built hubs and 2–4 inns per later leveling/frontier zone, with named objective clearings ready for future live content. Every inn has a paired flight stop; the atlas and minimap distinguish inns, flight stones and the five capitals. The Dawnlands surround Alderhaven, and mountain passes, highland crevasses and bridged coastal channels divide the zones. See [continent geography and travel](docs/CONTINENT.md) for authoring and exploration.

## Game and gameplay reference

An original, MIT-licensed multiplayer browser RPG. The first playable zone, **The Cinderwood Reach**, takes four playable classes from level 1 to 10, from Hearthstead through the woodland trails and sanctuary to Willowcross and six outlying quest hubs. The eastern road now opens directly into **Alderhaven**, the human capital.

## Play

```bash
./start.sh --world emberwild
```

Open **http://localhost:3080** in a desktop browser with hardware acceleration. The launcher uses Node.js 22+ if installed; otherwise it downloads a checksum-verified, project-local Node.js 24 runtime for Linux/macOS, ARM64/x64. First setup needs internet access; subsequent play is self-hosted, with no CDN, account service, or model API required. On Windows, install Node.js 22+, then run `npm ci` and `npm start -- --world emberwild`.

Start by speaking to **Elowen**, ahead of the campfire: walk with **WASD**, approach her, and press **F**. She introduces you to Sera. After that introduction, follow small quest batches along the western trail. At level 2, Elowen teaches greetings and rewards your first new emote. Check **J** for available work; gold **!** and **?** markers show offers and completed objectives.

For a second player, open the same URL in another browser/private window, or choose **New character** on the character screen of another tab. A character can have one active connection. Friends on your LAN can visit `http://YOUR_HOST_IP:3080`; the server listens on all interfaces by default. Allow TCP 3080 through your own host firewall if necessary. Every player must use the same server address, rather than their own `localhost`.

```bash
HOST=127.0.0.1 PORT=3081 ./start.sh --world emberwild   # loopback only, alternate port
```

Use **/wave @nearby**, **/bow @nearby** or **/cheer @nearby** without selecting anyone. Nearby NPCs and creatures can notice within twelve paces. Plain commands use a suitable selected character, otherwise address the area; **/wave Name** also works. The chat header’s **Emotes** button and **P → Emotes** open the library: eight entries per page, mouse-wheel paging, search, and a **Show unlearned** checkbox (off by default). Class skills and General use the same fixed 2×4 layout. Shift-click or drag a learned gesture onto your action bar to bind it to a key. **C → Reputation** lists groups as you meet them. Hover each individual arrow board on a road sign to read only the destination it points toward.

Chat supports **/s or /say** (35 paces), **/y or /yell** (120 paces), **/1, /z or /zone** (General throughout the zone), **/w or /whisper Name message** (private to an online character anywhere), and **/p or /party** (your current party, regardless of distance). The chat header selects the channel for plain messages; an explicit public/party slash channel also selects it for subsequent messages. Whispers leave that selection alone. Guild chat `/g` is reserved and explains that guilds are not implemented. The expanded chat panel has **All**, **Whispers** and individual conversation tabs with unread counts and separate drafts. **New whisper** offers online friends, recent conversations and a full-name field; the composer shows exactly who receives your message. Drag the upper-right chat handle to resize it; its size is saved. Use **/friend Name** to save online or offline friends. **/friend** alone opens the add-friend form. Open the **Friends** bottom-menu button or **/friends** to see their status. Right-click a targeted player's portrait to whisper, add/remove a friend or invite them. **Town mailboxes** outside the Willowcross inn and beside all three Alderhaven inn return points send letters and up to six item stacks to offline characters. Right-click bag items while composing to attach them; collect parcels at any mailbox. See [chat and post design](docs/CHAT_AND_POST.txt). Form a party by selecting a player, choosing **Invite to party**, and having them accept. Nearby `/say` can get an NPC answer about work, directions, their people, gestures, or the inn. NPC emote replies combine varied gestures with written lines and local speech bubbles. These are authored dialogue rules, with no model service required.

The [starter region refinement guide](docs/STARTER_REGION_REFINEMENT.md) describes the doubled northern quest area, the eight-times-larger surrounding region, expanded Willowcross, six distant hubs, the capital road and near-level-10 reward budget. Every character knows **Hearthward Return** (P → General, 8-second cast, 15-minute cooldown). Speak to **Merrin inside the Willowcross inn** to bind it there; the default return is the initial spawn.

## Alderhaven and the wider world

Follow the signs from Willowcross through Wayfarer’s Watch, then east along **Alderhaven Road**. The open western arch leads into the human capital without a loading screen. Eight wards span an approximately 840 × 780 metre footprint: the Open Gate, Fourwinds Exchange, Concord Heights, the Unfinished Archive, Bellfounders’ Close, Lantern Gardens, Lowdoor Ward and the Willow Quays. Forty-five buildings include walk-in halls, homes, workshops and guest pavilions, with taller civic landmarks and city walls.

Meet five principal characters with distinct ceremonial clothing and optional conversation choices. The First Speaker recognizes your completed Reach amendment; the archive keeper, bellfounder, Lowdoor representative and Sera’s sister develop existing story threads without adding capital quests. Inns offer **three city return hearths**. The **Common Vault** provides the existing bank, including right-click deposits/withdrawals and transaction cursors. Open **M** for the city chart; right-click up to the region chart to choose either playable area.

The Dawnlands now has **37 leveling zones, five capitals and ten level-100 frontiers** with four interconnected leveling routes. Cinderwood and Alderhaven remain populated; the other 50 maps provide traversable static geography and unoccupied architecture for later live content. Visit travel stones on foot to discover flight routes and capital portals. The playable cap remains 10. See [the continent, travel and authoring guide](docs/CONTINENT.md).

The city also has five moving residents: two patrols, two children with a school/home circuit, and Bessa Basket’s traveling provision shop. Speak or gesture to pause them. City streets climb toward Concord Heights, the archive and gardens, then descend to the quays. The arrival road now has a wider landscaped approach and gradual changes in fog and paving.

Live state and world events are partitioned into the Reach, city and a shared arrival overlap. Crossing players receive the overlap plus the nearer main zone; overlap actors retain one identity. Remote party health stays available separately. This remains one server process with the existing 64-player limit. See [zone replication](docs/ZONE_REPLICATION.txt). `npm run test:city-life` checks the visual handoff, moving NPC gait, absent remote-zone actors, trading with the traveling vendor and the raised city.

## Story and world reading

The starter campaign now tells **The Road That Forgot Its Guests**: old refuge work has turned an emergency promise to protect travelers into an order that cannot let them leave. The northern sanctuary resolves Hearthstead’s immediate danger; six distinct camp accounts then support a local repair and Willowcross’s concluding release amendment. Briar’s breadcrumb to Lysa follows the clean-amber finding; the existing harvest report is required for a new offer of the finale. Quest IDs, accepted progress, XP and equipment rewards stay compatible.

The internal [background story](game-data/story/cinderwood-background.txt), [story bible and 36 future threads](game-data/story/cinderwood-reach.json), and [future story development method](game-data/story/DEVELOPMENT_GUIDE.txt) live with the repository game data and are not publicly served. All 80 quest definitions have chapter scenes in `shared/story-content.js`. Seventeen short, attributed documents in `shared/readables.js` appear on open-book stands at camps and points of interest. Hover for a title and hand cursor; click nearby or press **F** to read, turn pages, and use **Escape** to close. Renn’s recovered journal and the sanctuary tablet examinations also reveal their text after gathering. Optional reading grants no repeat XP or items. Tamsin’s final amendment appears for your character after the finale. These are personal story outcomes; shared enemies continue respawning for other adventurers.

`npm run test:story` creates its own disposable server/profiles and checks world-book hover, click/F reading, pages, Escape, 1280×720 layout, journal examination, personal ending visibility, changed dialogue, and isolation of the author files. It needs the same browser/WebGL setup as the other browser checks.

Every action supports two optional bindings in **Game menu → Keybindings**, including middle, Back and Forward mouse buttons and modifier combinations. Existing custom assignments keep priority when new defaults are added. Left-drag free look preserves the movement heading; Q/E and right-drag steer that heading. Autorun is a local movement toggle and clears on menus, chat entry, focus loss, disconnect, death or logout.

Forward movement and pure strafing run at 6.5 paces per second. Backpedaling, including backward diagonals, moves at half that speed (3.25 paces per second), using the same rule for local prediction and server authority. The lower body turns into forward/sideways travel while the torso and head retain the look heading. Backward travel uses shorter reversed steps, with the legs angled to match backward diagonals. These local animations also apply to other players and preserve terrain-aware foot placement and equipped gear.

Camera pitch reaches roughly 69° upward and 85° downward. Ground clearance preserves the requested look angle. Camera drags use the browser’s Pointer Lock API to hide and confine the cursor, with relative movement continuing past window edges. Releasing the mouse restores the original cursor location; Escape, focus loss, menus and disconnect also release capture. Left-drag captures after the click/drag threshold, so ordinary selection clicks still work. If the browser blocks capture, the cursor stays visible and a message explains how to allow it.

Melee requires being within 3.6 paces. Dawnwarden attacks stay close; bow and spell classes fight at longer ranges. Auto attack continues while using skills. Run to break pursuit; health recovers after seven seconds outside combat. Open a defeated enemy with F or right-click, then take individual items/coins or choose Loot All. Shift quick loots. Quest equipment rewards enter your backpack; right-click them to equip. Old equipment moves into your bags. Quest drops occupy bag slots and are consumed on turn-in. Sell trade goods and buy tonics or bags from Tavi. There is no item loss on death.

## Enterable buildings

Walk straight through the open doorways in Hearthstead; there are no loading screens or separate instances. **Wayfarer’s Lodge** is southwest of the hearth, **Trailkeeper’s Workshop** southeast, and **Sera’s Cottage** northwest. The lodge and workshop entrances face north toward camp; the cottage entrance faces south. Signs identify each building.

Interiors have deliberately generous 5.8–6.2 metre wall heights and 4.4–4.6 metre doorways, flush wooden floors, furniture, and warm light. Roofs cut away and camera-facing/obstructing walls fade locally so the third-person camera can see your character. Wall and furniture collision still applies while they are faded. The exterior returns when it no longer blocks the view. Other players share the same rooms, and logging out or reconnecting inside preserves your position. The room name appears in the top location bar.

Tables and furniture now have solid sides and supporting top surfaces. **Space** plus movement can jump onto Tavi’s outdoor table or the tables, beds, counters and crates inside buildings. You can stand, cast, jump again or log out on a surface; stepping off falls naturally to the next surface below. Fence rails block walking and can be jumped over or balanced on; their taller posts require jumping from a raised surface. Small sanctuary steps can be walked up. Gateposts, lantern poles and ruin columns also block movement. Collision includes ceilings/lintels, so raised jumps cannot pass through them. Supply crates remain as physical props after their personal quest interaction.


## Interface

Quest conversations use movable parchment windows at the side of the screen. Select a quest from the NPC’s list, read its objectives and rewards, then Accept or Complete Quest. Completing a quest returns to the conversation without a fullscreen interruption. The quest log defaults to current quests, with available/completed tabs. Windows leave the world visible, can coexist, and do not stop movement; walk away to close a conversation or corpse window. Escape closes the topmost window. While the player moves, open game windows fade to 45% opacity and restore when the player stops. The quest log includes **Abandon Quest** with confirmation: progress and its dedicated quest items are removed, and it can be accepted again from its giver.

**Backpack & bags (B):** separate bag grids are the default. Check **Combine bags into one** to use a single virtual grid; this browser preference and your item arrangement survive reconnects and character changes. There are twenty base slots and four equipped bag slots, stacks up to 99 (one per slot for equipment and bags), rarity borders, quest-item markers, free-space count, and copper/silver/gold display. Right-click equipment to equip, right-click tonics to drink, and drag items between bag slots to arrange them. **Character (C)** shows a full paperdoll with 19 equipment positions and stats; right-click equipped gear to put it in your backpack, or drag compatible gear onto a slot. Hover over an inventory item to see the matching equipped item's icon, name and stats, plus green gains or red losses if you equip the hovered item. Comparisons show both compatible jewelry slots, empty slots, and identical items with no stat change. Keyboard focus also opens the tooltip.

Tavi sells **6-slot pouches (6 copper, level 1) and 8-slot satchels (18 copper, level 3)**. Larger bags belong to later regions: 10 slots at level 15, 12 at 25, then two more slots roughly every ten levels, reaching 28 at level 100. The abandoned-supplies quest also rewards an 8-slot satchel. Right-click a bag in your inventory to equip it, or drag it onto one of the four bag slots beside the backpack button. Click an equipped bag to view that container; use All to see everything. Right-click an equipped bag to remove it. Replacement/removal is refused if the remaining storage cannot hold your items and the returned bag. Item arrangement stays local to your browser; capacity and ownership are validated by the server.

**Equipment progression:** every slot is visible from level 1: head, neck, shoulders, back, chest, shirt, tabard, wrists, hands, waist, legs, feet, two rings, two trinkets, main hand, off hand, and relic. New characters start with only a weapon and chest piece. Empty later-game slots have icons and tooltips explaining that more gear will come as the world expands; they have no artificial level locks. Existing Trailkeeper’s charms appear in **Trinket 1**.

**Visible gear:** all three swords and all three coats have distinct original 3D appearances. Main hand, shield, hat, chest, legs and feet update on your character and other players when equipped or removed, and follow running, jumping, attacks and casting. Tavi sells an **Outpost buckler (14 copper)**, **Trailkeeper’s cap (10)**, **Roadwoven trousers (8)** and **Wayfarer’s boots (10)**. Close the shop before right-clicking purchases to equip them; right-click sells while trading. Empty slots restore plain base clothing, hair and empty hands. Jewelry, trinkets and other equipment positions currently have no attached 3D model.

Gear bonuses are summed across all equipped positions. Rings and trinkets can use either paired position: right-click selects an empty compatible slot (otherwise the first), while dragging chooses a specific slot. Hovering a bag item compares both compatible positions. Each equipped copy requires its own owned item; equipped copies stay out of bag slots and cannot be sold. Old three-slot saves migrate without changing their gear or bonuses.

**Targeting and parties:** left-click a character to select it; right-click an enemy to start autoattack. Left-clicking a character stops autoattack. NPC conversations use F or right-click. Click your own player frame to select yourself. Player and target frames sit above the action bar, player on the left and target on the right. Stormcaller’s Healing Rain heals a selected living friendly player or NPC within 24 paces; with an enemy selected or no selection, it heals you. The cast keeps its original recipient and checks range/life again on completion.

The selected target has a bright, dark-outlined rounded ring. It follows slopes and raised surfaces, retains thickness at shallow angles, and adjusts its size/stroke for distance. Friendly targets use mint and enemies use gold. Solid geometry still occludes the ring normally.

Select another player and click **Invite to party** above the target frame. They must Accept to join; groups hold up to five. The leader can invite, and the frames to the left and above your profile select members for healing. **Leave** exits. Disconnecting removes a member, promotes the next leader, and dissolves groups with fewer than two members. Parties and pending invitations are temporary and are not restored after reconnecting or restarting. Combat participation still determines XP and personal loot; party membership alone does not grant kill credit.

**Personal bank:** persistent, per-character storage with 28 base slots and stack/item transfers is implemented. It requires a nearby living banker and closes when you leave or die. Visit **Maraen Ledger at the Common Vault in Alderhaven’s Fourwinds Exchange** to access it. Equipped items/bags and quest items cannot be deposited.

**Spellbook (P):** Class and General tabs show learned abilities and future unlock levels. Drag a learned spell onto the **12-slot action bar**, or Shift-click to add it to an empty slot. Drag tonics from your backpack onto the bar. Shift-drag bar slots to swap them while locked, or use the lock button to unlock rearranging. Drag an unlocked action off the bar to remove it. Bindings, bag order, and Auto Loot preferences are saved in this browser. Empty slots and rearranged abilities change which action each numbered key uses; the table above lists defaults.

Character movement animation uses the locally predicted position every rendered frame, with distance-driven strides and smooth transitions between running, idle, jumping, and landing. Other players use their interpolated positions. Slopes shorten the visible stride and adjust foot placement; terrain height also places scenery and smoothly guides camera elevation. Walk through the camp’s northern gate to reach the rising trail toward the sanctuary.

All four class abilities share a **1.5-second global cooldown**, with a smooth radial sweep across learned skills on the action bar. It starts immediately when an ability begins and overlaps cast time; completion does not add another shared cooldown. Cancelling an unfinished cast releases its global cooldown immediately, including when moving, jumping or pressing Escape. Invalid abilities do not trigger it. Individual skill cooldowns still apply and take display priority when longer. Autoattack and tonics use their separate timers. The server enforces the lock, and the client predicts the sweep immediately and reconciles accepted/rejected requests without restoring cancelled casts from late acknowledgements.

Sundering Slash and Second Wind require standing still. Their cast bar starts immediately; moving, jumping, or Escape interrupts the cast. Energy is spent and cooldowns/effects begin only after successful server completion.

The minimap follows your predicted position and remains centered even near the edge of the zone. Use its **+ / −** buttons or scroll over the map to zoom between six local/overview scales. Numbered quest pins match the quest tracker; the selected quest has a highlighted objective area and a direction/distance card below the map. Hover for paired quest titles, objectives and progress; overlapping objective regions list all matching quests. Click a pin to track its quest (repeated clicks cycle clustered quests), or click an objective region to open the full map. Native map tooltips are suppressed so they do not cover quest details. Gold edge arrows point toward offscreen objectives; completed quests lead back to their turn-in NPC.

The **⌖ tracking button** opens checkbox groups. Expand **Objective types** to filter hunting/loot, gathering, exploration, deliveries/conversations, class practice, and ready turn-ins. These filters also affect the zone atlas and preserve quest numbering. Other groups toggle quest objectives, quest givers, inns/rest points, trainers/mentors, merchants, herbs, ore, other objects, and minimap enemies. Resource tracking starts off; services and quests start on. Sera marks the existing rest/recovery service and Orin the class mentor. Zoom and filters are saved in this browser.

**World atlas (M):** illustrated parchment charts show inked paths, forests, ridges, settlements and ruins. The hierarchy is **Emberwild → The Dawnlands → The Cinderwood Reach / Alderhaven**. Right-click the chart to go up one level; left-click an inked region to open its finer chart. Breadcrumbs, region buttons and the back button also navigate; **Find me** returns to your zone. With the chart focused, Left/Backspace goes up and Right/Enter opens a child. Blank parchment and unfinished survey edges are uncharted areas reserved for future content, rather than hidden existing quests. The zone chart retains quest areas/numbers, services, resource tracking and adventurers. Hovering numbered pins or overlapping objective areas uses the same quest-detail tooltip as the minimap; clicking tracks/cycles the quests. Parent charts show clickable quest-count badges for zones with current quests; your location appears on all ancestor charts. The minimap keeps its independent zoom and interaction controls. See [the atlas authoring guide](docs/WORLD_ATLAS.md) for adding future maps in the same style.

Ground quest objects, herbs and ore take a **one-second gathering cast**: approach, stand still, and press **F** or click. The cast bar starts locally; items and quest progress arrive only after successful completion. Moving, jumping, Escape or damage interrupts the pickup. Available ground objects show a hand cursor on hover. Herbs and ore can be gathered without a quest or profession. Sunmint and copper ore are sellable trade goods. Nodes recover after 45 seconds (herbs) or 60 seconds (ore), separately for each player, and disappear from that player’s world/map until ready. Remaining recovery time is saved and pauses while that character is offline. Gathering quests still require distinct nodes; repeated harvests from one node do not add extra quest credit.

The bar shows individual cooldown sweeps and remaining time, tonic count, energy shortage, melee/ranged distance feedback, and active autoattack. The micromenu at the bottom right opens equipment, spellbook, quests, map, and backpack.

**Loot:** opening a corpse does not grant items immediately. Click individual rows, choose Loot All, or use Shift quick loot. Each eligible player has their own contents. Full bags leave uncollected items on the corpse; coins can still be collected. Auto Loot can be toggled in the loot window; holding Shift temporarily reverses the setting.

**Merchant:** select “Let me browse your goods” when speaking to Tavi. His shop and your backpack open together. Click an item to buy; right-click an item in your backpack to sell one, or Shift-right-click to sell its stack. Equipped gear, equipped bags, and quest items cannot be sold. The trade-goods button sells resin, crystals, herbs, and ore in bulk.

## Game menu and preferences

Click **☰** in the top-right bar to open the game menu. **Escape** first cancels a cast, closes the tracking dropdown or top game window, or clears a target; when those are clear, it opens the menu. Inside Settings or Keybindings, Escape returns to the menu, then another Escape resumes play. Keyboard focus stays inside the menu while it is open. Movement keys and gameplay shortcuts are blocked there, and opening it clears held movement/camera dragging. The shared world continues to run.

**Settings** apply immediately: synthesized sound and master volume, camera-drag sensitivity, Low/Balanced/High graphics quality, foliage/water motion, FPS/network-latency display, and Auto Loot. Low graphics disables shadows and caps pixel ratio at 1; Balanced caps at 1.5 and High at 2. Device pixel ratio remains the upper bound. These preferences are saved per browser. Auto Loot shares its preference with the corpse window.

**Keybindings** covers movement, jumping, interaction, enemy targeting, chat, game windows, and all twelve action slots. Each action has two optional bindings. Click a binding and press a physical key, optionally with Ctrl/Alt/Shift; Escape cancels capture. Clear with the adjacent ×. Assigning a key already in use removes the old assignment and names the affected action. Movement, action-bar labels, and shortcut hints update immediately. **Restore default keybindings** recovers the original layout. Escape remains reserved for menu/cancel and bare / for emote chat, and common browser/OS shortcuts cannot be assigned. Shift-interact retains quick-loot behavior unless that modified key is explicitly assigned to another action. The controls table above lists defaults.

**Log out** saves the character on the server, removes it from the world/party, waits for confirmation, and returns to the title screen. Your browser identity, action layout, inventory order, and preferences stay in the browser. Select a character and choose **Enter the Reach** to resume, or select another character. Normal logout does not show a connection-loss overlay. A failed write or lost confirmation is reported instead of claiming the latest state was saved. If already disconnected, use **Return to title** to leave the reconnect screen.

## Saves

Character creation uses selectable race portraits and class crests. Hover or keyboard-focus a choice for its background, physical traits or class fantasy, armor training, resource and early skills. Unavailable classes remain visible with a cultural explanation. Race determines appearance and available class traditions; starting stats and abilities come from the class, with no racial stat bonuses.

The browser keeps a random roster access key in local storage (`emberwild-account`). It identifies up to **12 characters** on this server, without a username or password. The server atomically writes the roster, order and character saves together to `data/characters.json` when characters are created/deleted/reordered, on explicit logout/disconnect, every 10 seconds, and on graceful shutdown. `DATA_DIR` selects another save directory. **Back up this directory and preserve your browser’s site storage.** Clearing that storage loses access to the roster through the UI. Each browser profile and server address has its own identity; different tabs at the same address share a roster. Server files include the tokens and must remain private. Tokens are omitted from other players’ snapshots.

This intentionally simple local/LAN identity model has no passwords, account recovery, cloud sync, or cross-device login UI. Use HTTPS/WSS and proper accounts before making a public service. Abrupt process/machine failure can lose the most recent 10 seconds of progress. A corrupt save file causes startup to stop rather than silently overwrite characters.

The connection screen lists names and levels and previews the selected character with its actual equipped 3D gear. Drag the model or use the rotation buttons; scroll over it to zoom, or choose **Full body** / **Face** views. **New character** offers four appearance presets and **More appearance options**: eight skin tones, eight hair colors, six hairstyles, four facial-hair styles, five eye colors, three face shapes and three builds, with a randomize button. Choose **Create & enter the Reach** or **Create character without entering**.

To change an existing character, log out and select **Customize appearance**. Save appearance commits the changes; Cancel restores the saved look. An equipped hat is hidden only while editing the preview, so you can inspect hairstyles. Equipment, progression and position are preserved. Appearance changes are visible to other players after entering the world. Drag character rows or use their ↑/↓ buttons to save a different order. The × button opens a confirmation naming the character and level; **Keep character** or Escape cancels, and **Delete permanently** removes the character and its progress. Online characters cannot be edited, deleted or entered twice.

Roster changes are committed before success is shown. Concurrent tabs use revisions: a stale edit reloads the current list and asks you to review/retry. Failed saves leave the roster intact. Old single-character files migrate automatically, and the character previously remembered by this browser is imported into its roster. No character wipe is required.

## Scope and next steps

The initial playable slice is ready for testing. Travel time and real human leveling pace still need playtest feedback. Art uses simple geometric models; terrain/tree/character collision, animation, sound, accessibility, and performance remain prototype quality. Building walls, solid furniture, and zone borders collide; trees and actors currently do not. Local movement and jumping use client prediction with server-validated replay. Damage, healing, inventory, and quest rewards remain server-confirmed. Severe network stalls still cause pauses/corrections; this prototype does not implement full combat rewind or a spell-queue system.

There is no player trading, PvP, crafting/profession system, dungeons, account service, multi-server zone handoff, sharding, production database, or production-scale load validation. The 64-client check is a short functional capacity check, not proof of MMO-scale performance. Future local AI should propose validated, versioned content through the data/simulation boundary; it is intentionally absent from this playable base.

Project game text, models, and generated geometry are offered under MIT; see [origin and licensing](PROVENANCE.md) for the AI provenance and license scope. This project uses general RPG mechanics and includes no World of Warcraft client/server code, maps, dialogue, music, models, or other Blizzard assets. Third-party license information is in [THIRD_PARTY.md](THIRD_PARTY.md).
