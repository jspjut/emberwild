# Emberwild source-built art collection

The complete catalog contains 881 entries: 208 creatures, five playable race models, 637 equipment appearances and 31 world props. This retains 792 curated designs and adds 89 appearances used by live game equipment. Dormant item templates reuse their curated art entries rather than duplicating catalog records.

Forty new armor sets cover ten level bands for cloth, leather, mail and plate. Each has eight rigged pieces, and every slot changes physical shape between bands. The original eight sets remain, for 48 complete outfits. Eleven weapon/offhand families each gain ten different shapes. Regional palettes add color variations independently of shape.

Optional generated exports include 929 GLBs (881 individual entries and 48 assembled outfits), their transparent previews, 637 equipment SVGs, the complete catalog and a manifest with dimensions, animation names, collision hints and SHA-256 hashes. All 15 palettes are available from source and in the workshop. Open `/asset-library.html` or `catalog.html` on the running server to inspect the collection. Generated files stay out of Git and are rebuilt for release/website artifacts.

One unit is one meter; +Y up, +Z forward, ground-origin models. Materials and geometry are original code-built art under MIT; no external textures are required. All five race rigs support full-set and single-piece try-on, animation and GLB/PNG export. Acquisition notes and future level ranges describe authoring plans, not new drop tables. The live level cap is ten; the planned cap is 100.

See `docs/ASSET_LIBRARY.md` and `docs/EQUIPMENT_PROGRESSION.md`. The complete index is `shared/complete-assets.js`; curated art is `shared/asset-library.js`; progression shapes are generated by the engine’s `client/equipment-progression.js`. Rebuild the entire library with `npm run build:world-assets` from the engine. Unused original generators are retained.
